# Liquid Rocket Engine Designer

A Python tool for the preliminary design and performance analysis of small liquid
bipropellant rocket engines. Wraps NASA CEA (Chemical Equilibrium with Applications)
for propellant chemistry and adds nozzle sizing, altitude performance, feed system
closure, and thermal analysis on top.

## Design Point

- **Thrust:** 1 kN
- **Propellants:** LOX / Ethanol
- **Feed system:** Pressure-fed
- **Optimization:** Sea-level operation
